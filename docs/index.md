## Sobre o Projeto

O projeto utiliza ferramentas **Open-Source** para criação de um sistema que tem o intuito de  identificar se notícias durante o período eleitoral são verdadeiras ou não. Esse Software visa ajudar jovens que utiliza o Instagram a verficiar se alguma notícia durante o periodo eleitoral são verdadeiras ou não.

Após a verificação feita pelo **Modelo de Machine Learning (ML)**, o Software faz uma breve análise para verificar se a nóticia trata-se de algo **Real** ou **Falso**, e faz uma postagem na plataforma **BlueSky**, caso contrário, o POST é apenas ignorado.
